# NavMin

Система автоматического обнаружения и наведения для борьбы с БПЛА

## Как просматривать

- `mkdocs serve` - Запустить сервер с автообновлением в реальном времени
- `mkdocs build` - Собрать сайт с документацией (файл /site/index.html)
