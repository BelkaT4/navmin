# NavMin

NavMin — система BelkaT4 для моторизованного поворотно-наклонного штатива камеры, который наблюдает за летающими объектами на спортивных соревнованиях. Система принимает видеопотоки, обнаруживает и сопровождает выбранный объект, чтобы удерживать его в центре кадра или использовать прогноз движения для опережающего кадрирования. Внутренние названия `Vision`, `Aiming` и `Turret` относятся соответственно к обработке изображения, расчёту положения объекта и управлению приводами штатива через STM32.

В обычном тексте используется термин **отслеживаемый объект**. Слова `target`, `TargetRef`, `selected_target`, `Aiming`, `Turret`, `TRACKING` и другие точные имена из кода не переименовываются: они приводятся буквально и при необходимости поясняются по смыслу.
