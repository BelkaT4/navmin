## Установка и использование

- Установка с основными зависимостями
```
pip install .
```

- Установка с дополнительными dev‑зависимостями
```
pip install -e .[dev,docs]
```

- Запуск линтера
```
ruff check .
```

- Запуск тестов
```
pytest
```

- Просмотр документации локально
```
mkdocs serve
```

- Сборка документации
```
mkdocs build
```
